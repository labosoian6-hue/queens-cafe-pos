ℹ How Modifiers Work

When a cashier taps a menu item that has modifiers, a popup will appear listing all available options (e.g. "Extra Cheese +50", "No Onions"). The cashier can select one or more modifiers. The selected modifiers' names and price adjustments are reflected in the order item name and price. Items without modifiers are added directly to the order as before.
